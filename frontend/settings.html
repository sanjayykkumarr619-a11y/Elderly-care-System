Medication Rules

  • A dose becomes MISSED if not confirmed within 30 minutes of its scheduled time.
  • TAKEN doses reduce stock by the dosage amount. MISSED doses never change stock.
  • Once a dose is TAKEN or MISSED, it cannot be changed again - this prevents duplicate stock deductions.
  • Confirming a dose is blocked if there isn't enough stock to cover it.
  • Taken/missed/low-stock/refill events are emailed to every active recipient above.
  • A low-stock alert (and email) fires once per dip below the threshold - refilling above the threshold resets it, so the next dip alerts again.

About This Prototype

This is a software-only prototype. Camera Monitoring and Smart Home Control use simulated virtual devices today. The backend includes a device abstraction layer (devices/device_manager.py) and hardware-ready APIs (robot, sensors, cameras, smart devices) so a Raspberry Pi with real sensors, relays, motors, and cameras can be connected later without changing this frontend.

Data is stored locally in SQLite at database/elderly_care.db, scoped per account, and survives server restarts and browser refreshes.
